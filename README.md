# FYTTS — Interactive Prototype

A responsive webpage embedding the FYTTS Figma prototype. It includes restart, full-screen and direct Figma controls.

## Website

The complete static website is in `index.html`. No installation or build step is required.

## GitHub Pages

The site publishes from the repository's `main` branch and root folder through **Settings → Pages → Deploy from a branch**.

Updates to `index.html` on `main` automatically trigger a new Pages deployment.

The embedded prototype retains its Figma access permissions. Updating the Figma design updates the embedded content without rebuilding this page.
